# Claude CNN 후보의 학습 코드 검토

받은 모델은 `sirius_cnn_v1` 후보이며 기존 앱의 활성 모델로 바꾸지 않았다. 과거 archive.zip의 99.2%와 현재 데이터의 점수는 평가 집합·분할이 달라 직접 비교할 수 없다.

확인하고 수정한 문제:

- 요청한 학습/검증 경로만 전달해도 기존 로더가 전체 데이터 폴더를 순회하며 테스트 영상까지 미리 열었다. 테스트 라벨을 손실 계산에 사용했다는 증거는 아니지만, 테스트 영상을 열지 않는다는 설명과 달랐다. 지금은 지정한 split의 요청 파일만 연다.
- 캐시의 원본 데이터 루트와 파일 내용 검사가 없어 데이터가 바뀌어도 오래된 픽셀을 재사용할 수 있었다. 루트와 SHA-256을 검사하며 pickle 캐시는 허용하지 않는다.
- 배치 크기로 나누어떨어지지 않는 마지막 학습 표본이 누락되었다. 마지막 작은 배치까지 학습하고, 작은 데이터에서도 실제 최적화 단계가 수행되게 수정했다.
- 기존 출력 폴더를 덮어쓸 수 있었다. 새 출력 폴더만 허용한다.

실제 검증:

- 손상된 미선택 테스트 파일이 있어도 학습 영상만 정상 로딩한다.
- 파일 변경 시 캐시를 갱신하고, 변경 없는 요청은 재사용한다.
- 허용하지 않은 split와 데이터 루트 밖의 파일은 거부한다.
- 공개 MRI의 소규모 표본으로 학습 8장·검증 4장, 배치 64, 1 epoch를 실제 수행해 유한한 학습 손실과 체크포인트를 확인했다. 성능 평가용 실행은 아니다. 별도 로더 회귀 테스트에는 합성 이미지를 사용했다.
- 기존 그룹 분할의 학습 3,540장·검증 885장으로 새 22 epoch 학습을 시작했다. 테스트 영상은 복사하거나 열지 않았다. 전체 Python 회귀 테스트 20개가 통과했다.

공개 프로토콜은 `sirius-grouped-protocol.json`, 실행 방법은 `ml/candidates/sirius_cnn_v1/REPRODUCE.md`에 있다. 데이터·가중치·배열 캐시는 공개하지 않는다. 외부 출처·환자 단위 독립 평가와 별도 보정 검증은 아직 필요하다.
